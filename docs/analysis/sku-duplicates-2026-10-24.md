# SKU 档案疑似重复分析（2026-10-24，只读）

范围：库中 147 个 ACTIVE SKU 逐对比较，命中 3 对。

## 置信度定义（宁可漏报，不可误报）

| 档 | 判定依据 | 含义 |
|---|---|---|
| A | 同店同平台变体 / 同条码 / 同图片 | 平台侧或实物证据已指向同一件货 —— 几乎确定 |
| B | 名称签名完全一致 + 同品牌或同分类；或跨店铺共用同一平台商品标识 + 名称签名一致 | 极可能同一实物 |
| C | 名称签名包含关系（多出的词不是颜色/版本） | 两个档案的叫法一个比另一个更啰嗦 —— 很可能 |
| D | 仅字符串相似 ≥80% | 只能当线索，不建议直接合并 |

**硬反证（出现即不进 A/B/C）**：品牌不同、颜色词元不同、型号词元不同（`A5` vs `A7`、`V9 Pro` vs `V9 Pro 2`、`TURBO` vs `TURBO+`）、model/color/size 字段不同。

**方法说明**：名称按 `-／空格／全角半角／大小写` 归一化（`+` 保留为型号词元，所以 `TURBO` 与 `TURBO+` 不会被当成同一型号），去掉品类词（鼠标/键盘/耳机/保温杯…）与品牌前缀后作为「名称签名」。同一位置上的短词元互换（迷雾/赵芸、玄影/流影）视为配色不同而排除。分组只沿 A/B 证据连通（C/D 单列），避免 A≈B≈C 连锁误合并。
