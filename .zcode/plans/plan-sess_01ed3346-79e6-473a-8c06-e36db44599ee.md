# 安装 show-me 为 ZCode 个人 skill

## 目标
将 humanlayer/skills 仓库中的 show-me skill(MIT 许可,单个 3.3KB 的 SKILL.md,纯 prompt 无可执行代码)安装为个人 skill,不引入任何 marketplace 来源。

## 允许修改的范围
仅 `C:\Users\Administrator\.zcode\skills\show-me\`(用户级 skill 目录,不在 WCIES 工作区内,不触碰项目代码)。

## 步骤
1. 创建目录 `C:\Users\Administrator\.zcode\skills\show-me\`
2. 用 curl 从 raw.githubusercontent.com 下载原始 SKILL.md 到该目录(保留原始内容,不自行改写):
   `https://raw.githubusercontent.com/humanlayer/skills/main/plugins/show-me/skills/show-me/SKILL.md`
3. 校验:文件约 3297 字节,frontmatter 含 `name: show-me` 和 description,正文完整(8 种可视化形态 + 收尾原则)。

## 验证与说明
- 安装后告知用户:新 skill 一般在新会话中生效;可通过 skill 列表确认,或在对话中直接说"用图解释一下 xxx"观察是否自动触发。
- 不修改 WCIES 仓库任何文件,不需要 Migration/测试(与项目代码无关)。

## 回滚
删除 `C:\Users\Administrator\.zcode\skills\show-me\` 目录即可完全卸载。
